1. 我们处理哪些信息及用途

  • TapTap 登录：同意后，游戏通过 TapTap PC 客户端和 TapSDK 完成渠道启动验证与账号登录，请求基本资料授权。SDK 可处理账号标识（OpenID、UnionID）、昵称、头像及登录凭证，用于识别登录状态；游戏不请求电子邮箱授权，也不要求您向运营者提供 TapTap 密码
  • 必要的设备与连接信息：TapSDK Core/Login 会为兼容性、服务配置、登录通信及安全运行处理适用的 Windows 系统、设备硬件、应用版本和网络连接信息（包括通信时的 IP 地址）。TapSDK Core 还会处理设备与安装标识、应用启动、前后台切换和会话时长等 SDK 运行信息，用于基础服务统计、会话管理和运行诊断，由 TapTap 按其政策处理。SDK 的处理规则见第2节。AndroidID、手机通讯录、相机、麦克风和定位权限不属于本 Windows 版本的功能要求
  • 本地游戏数据：游戏在您的设备保存进度、存档、设置、游玩记录和已同意的政策版本，以便继续游戏和记住选择；运行日志、主动截图或录像也保存在本地。运营者未接入用于上传这些存档或游玩统计的自建服务器
  • 主动联系我们：您发送邮件时，我们会收到回复所需的邮箱地址以及您主动提供的问题和材料，仅用于处理该请求。请不要发送账号密码或与问题无关的敏感资料

本版本已移除 Unity Analytics，并关闭 Unity 可选统计/诊断上传及 TapTap Event 事件统计。游戏不以广告、个性化推荐或营销画像为目的处理上述信息

本地数据保留在您当前使用的设备，直至您通过游戏删除存档或自行删除相应数据；卸载程序不一定会清除所有用户数据。TapSDK 管理登录缓存及相关服务端数据，其地点、期限和依法删除规则以该 SDK 政策为准。我们处理的联系邮件仅在解决请求及履行必要法定义务所需期间保留，期满后删除或匿名化；不进行无期限的额外保存

4. 共享、转让与安全

我们不出售您的个人信息。除您授权使用的上述 SDK、处理请求所必需的服务或法律要求的情形外，不向其他主体提供您的信息；处理目的、方式或接收方发生重大变化时会依法另行告知并取得必要同意。我们采取最小化处理、限制访问和使用 SDK 的传输保护措施；发生安全事件时将依法处置并通知受影响用户。网络和设备环境无法保证绝对安全

進行状況、セーブ、設定、プレイ記録、同意した版、実行ログ、利用者が撮影した画像・動画は端末内に保存します。運営者はこれらのセーブやプレイ統計を送信する独自サーバーを設けていません。問い合わせメールは返信先と提供された内容をその対応にのみ使用します。パスワードや無関係な機微情報を送らないでください。Unity Analytics は削除し、Unity の任意の統計・診断送信および TapTap Event の統計も無効にしました。広告、個別推薦、マーケティング分析には使用しません。

2. 第三者サービス

TapSDK Core / TapTap Login 4.10.9（提供者：易玩（上海）网络科技有限公司）を、起動元の確認、ログインと必要な基盤機能に使用します。同意後に初期化し、基本プロフィールのログイン認可を行います。TapSDK のポリシー、SDK 連絡先：privacy@taptap.com。クラウドセーブ、フレンド、ランキング、決済、TapTap データ分析は組み込んでいません。

ローカルデータは利用者が削除するまで端末に残ります。アンインストールですべて消えるとは限りません。SDK のキャッシュとサーバーデータの場所、期間、削除は SDK のポリシーに従います。問い合わせメールは対応と必要な法的義務の期間のみ保持し、その後削除または匿名化します。個人情報を販売せず、認可された上記サービス、対応に必要なサービス、法的要請を除いて第三者に提供しません。重要な変更では通知と必要な同意を行います。最小限の処理、アクセス制限、SDK の通信保護を用い、事故時は法令に従って対応・通知します。完全な安全性は保証できません。
